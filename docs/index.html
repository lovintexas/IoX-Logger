IoX Logger

Version 1.1.0 — Historical node-value logging and automatic IoX program execution monitoring, with a secure local web interface.

IoX Node Logging Program Logger HTTPS CSV Export

Overview

IoX Logger is a plugin for Universal Devices IoX that records selected node and driver values and monitors program THEN and ELSE executions.

The local web interface provides historical graphs, program execution history, configuration controls, and CSV downloads.

Node Logging Features

  • Discover native IoX nodes and installed plugin nodes
  • Log selected node and driver values
  • On-change or fixed-interval logging
  • Enable, disable, edit, and delete individual loggers
  • Graph historical values
  • Download historical CSV data
  • Automatic CSV rotation and storage management
  • Friendly driver names for plugin devices

Program Logger — New in 1.1.0

  • Automatically monitor IoX program THEN and ELSE executions
  • Monitor discovered programs without modifying them
  • Enable or disable program logging
  • Search, sort, and page through execution history
  • Download program history as CSV
  • SQLite history storage
  • Configurable retention from 7 to 365 days

Requirements

  • Universal Devices eisy with a compatible plugin environment
  • IoX controller
  • Unrestricted IoX access permission enabled for the plugin
  • TCP port 8765 available
  • Local IoX administrator credentials for program monitoring

Installation & Required Permission

Install IoX Logger from the Universal Devices Plugin Store.

  1. Open IoX Logger in the plugin management interface.
  2. Go to Configuration.
  3. Enable Allow Unrestricted ISY Access by Node Server.
  4. Restart IoX Logger if necessary.

Required: Without unrestricted IoX access, IoX Logger cannot retrieve the IoX node catalog or log node values.

HTTPS Web Interface

After the plugin starts, open:

https://<eisy-ip-address>:8765

Example:

https://192.168.1.100:8765

The web interface uses HTTPS with a locally generated self-signed certificate. Your browser may display a certificate warning.

Administrator Authentication

On first use, create an administrator password. Subsequent visits require login.

  • Session-based login and logout
  • Password change and recovery
  • Automatic session expiration after inactivity

Security: Keep the interface on your trusted local network. HTTPS and authentication do not make it appropriate to expose directly to the Internet.

Creating a Node Logger

  1. Select an IoX source.
  2. Select a node.
  3. Select the value or driver to log.
  4. Choose a logging mode:
    • On Change — record values when they change.
    • Fixed Interval — record values at the selected interval.
  5. Create the logger.

Once data has been collected, view it as a graph or download a CSV file.

Managing Node Loggers

Individual loggers can be enabled, disabled, edited, or deleted from the web interface. Fixed-interval loggers can have their intervals adjusted.

Program Logger Configuration

Program Logger monitors IoX program execution events through the native IoX event stream.

Local IoX Credentials

Enter the local IoX administrator username and password in the Program Monitor configuration.

Not Portal Credentials: These must be your local IoX credentials, not Universal Devices Portal credentials. They are also separate from your IoX Logger web administrator password.

Enabling Program Logging

  1. Open the IoX Logger HTTPS web interface and sign in.
  2. Navigate to the Program Logger section.
  3. Configure the local IoX credentials.
  4. Enable program logging.
  5. Choose a history retention period.

Once connected, program THEN and ELSE execution events are recorded automatically. No changes to individual IoX programs are necessary.

Program Execution History

The Program Logger history viewer provides a searchable, sortable, paginated table of execution events.

  • View program names and execution information
  • Distinguish THEN and ELSE executions
  • Search execution records
  • Sort the history table
  • Navigate through pages of records
  • Download history as CSV

Program History Retention

Select the desired automatic retention period:

SettingRetention
7 daysOne week
14 daysTwo weeks
30 daysApproximately one month
60 daysApproximately two months
90 daysApproximately three months
180 daysApproximately six months
365 daysOne year

Program history is stored in SQLite. Records older than the configured retention period are automatically removed.

Data Storage

Node Logger Storage

Node logger configuration and historical CSV data are stored locally on the eisy. CSV files are automatically rotated and storage limits enforced.

  • 2 MB per CSV file
  • 10 MB per logger
  • 1 GB total node-logging storage

Program Logger Storage

Program execution history uses a separate SQLite database with configurable time-based retention.

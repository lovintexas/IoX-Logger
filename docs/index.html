IoX Logger

A PG3x plugin for Universal Devices IoX that records node and driver values for historical analysis.

Overview

IoX Logger discovers native IoX nodes and installed plugin nodes, records selected driver values, and provides a local web interface for managing loggers and reviewing historical data.

Features

  • Discover native IoX nodes and installed plugin nodes
  • Log selected node and driver values
  • On-change or fixed-interval logging
  • Enable, disable, edit, and delete individual loggers
  • Graph historical data
  • Download data as CSV
  • Automatic CSV rotation and storage management

Requirements

  • Universal Devices eisy running PG3x
  • IoX
  • Unrestricted IoX access permission enabled for the plugin
  • TCP port 8765 available on the eisy

Installation & Required Permission

Install IoX Logger from the PG3x Plugin Store.

IoX Logger requires direct access to IoX so it can discover nodes and read their values. After installation:

  1. Open IoX Logger in PG3x.
  2. Go to the Configuration page.
  3. Enable Allow Unrestricted ISY Access by Node Server.
  4. Restart IoX Logger if prompted or if the plugin was already running.

Required: Without unrestricted IoX access, IoX Logger cannot retrieve the IoX node catalog or log node values.

Web Interface

After IoX Logger is running, open the following address in a web browser:

http://<eisy-ip-address>:8765

Replace <eisy-ip-address> with the IP address of your eisy. For example:

http://192.168.1.100:8765

Local network only: The web interface currently does not provide user authentication and should not be exposed directly to the Internet.

Creating a Logger

  1. Select an IoX source.
  2. Select a node.
  3. Select the value/driver to log.
  4. Choose the logging mode:
    • On Change — records a new value when it changes.
    • Fixed Interval — records the value at the selected interval.
  5. Create the logger.

Once data has been collected, it can be viewed as a graph or downloaded as a CSV file.

Managing Loggers

Individual loggers can be enabled or disabled, edited, or deleted from the local web interface. Fixed-interval loggers can have their logging interval adjusted as needed.

Data Storage

Logger configuration and historical data are stored locally on the eisy. Logger data is kept in the plugin's local data directory.

CSV files are automatically rotated, and older files are removed as configured storage limits are reached.

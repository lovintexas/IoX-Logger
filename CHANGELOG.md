# Changelog

All notable changes to IoX Logger will be documented in this file.

## 1.0.2

- Added Configuration page help.
- Added instructions for enabling the required "Allow Unrestricted ISY Access by Node Server" permission.
- Configuration help is now displayed directly within the PG3x plugin Configuration page.

## 1.0.1

- Added installation and first-use documentation.
- Documented the required unrestricted IoX access permission.
- Added local web interface and security information.
- Added logger creation instructions.
- Cleaned up distribution files.

## 1.0.0

- Initial release.
- Native IoX and plugin node discovery.
- On-change logging.
- Fixed-interval logging.
- Historical graphing.
- CSV data export.
- Logger enable, disable, edit, and delete controls.
- Automatic data rotation and storage management.
